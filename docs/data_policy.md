# 数据与合规边界

本项目是教学/作业用途的 research agent 原型，只处理公开网页和用户主动输入的研究问题。

## 原则

- 不绕过登录墙、验证码、付费墙或访问控制。
- 不保存 API Key、Cookie、Authorization header。
- 不编造来源，引用必须来自实际搜索和抓取链路。
- 不长期保存网页全文，默认只输出最终 Markdown 报告。

## 网络访问

- 使用普通 HTTP 请求和明确 User-Agent。
- 设置 timeout，失败时跳过而不是重试轰炸。
- 后续如需增强，应增加 robots.txt 检查、缓存和限速。

## 输出

默认输出为 `outputs/report.md`，其中可能包含：

- 用户研究问题
- 自动生成子问题
- 网页摘要
- 参考来源标题与 URL

不应包含真实密钥、登录态或个人敏感信息。
